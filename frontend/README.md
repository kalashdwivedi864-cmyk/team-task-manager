# Team Task Manager 🚀

A full-stack Team Task Manager web application built using React, Flask, SQLite, and JWT Authentication.
# 🌐 Live Demo

https://team-task-manager-production-09cd.up.railway.app

# ✨ Features

- User Signup/Login
- JWT Authentication
- Role-based access
- Project creation
- Task assignment
- Dashboard analytics
- Overdue tracking

# 🛠️ Tech Stack

## Frontend
- React.js
- Axios
- CSS

## Backend
- Flask
- Flask SQLAlchemy
- SQLite

## Deployment
- Railway

# 🔐 Roles

## Admin
- Create projects
- Assign tasks
- Manage tasks

## Member
- View assigned tasks
- Update task status
